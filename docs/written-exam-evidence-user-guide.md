# Written Exam Evidence — User Guide

From **Driver Training → Assessments → Written Exams**:

1. Select the driver assessment.
2. Record the Theory and Road Signs scores if they are not already recorded.
3. In **Upload written exam evidence**, select the same assessment.
4. Choose the evidence type: Theory paper, Road Signs paper, Answer script, Marking / result sheet, or Other evidence.
5. Choose a PDF, JPEG, PNG or WebP file up to 4 MB and select **Upload file**.
6. Confirm the file appears in the **Written Exam Evidence Register**.
7. Use **View** to open the protected file or **Download** to save a copy.

VIMS accepts multiple written-exam files per assessment. Uploaded evidence is private and is only delivered after Driver Training access is verified.
